# Установка Strata и скачивание моделей

Status: resolved
Type: task
Blocked by: 01

## Question

(Исполняемая задача) Установить Strata нативно и подготовить три модели к замерам:

- Установить по командной строке из ответа тикета 01 (путь установки, порт `:8081`).
- Скачать/установить размеры: IQ3_XXS, IQ3_S, IQ2_XS (`./setup.sh --setup` на каждый;
  общие шарды не докачиваются повторно).
- Проверить: конфиги `strata-<model>.json` на месте, движок стартует `--help`/dry-run
  без GPU-работы, порт не конфликтует с llama-swap.
- NOT touch: не поднимать Strata на время работы текущего стека; только установка/докачка
  (диск, не GPU/RAM).

Resolved when: три модели установлены, пути/версии/размеры на диске записаны в ответ.

## Answer

Выполнено (2026-10-18). Strata клонирован в `/opt/strata` (HEAD main на дату; движок собран
из исходников nvcc — готовый бинарник `/opt/strata/engine/strata`, собран под CUDA 13.3,
`strata --help` и `serve/server.py --help` отвечают).

**Установлены и докачаны три размера** (директории — по клону-setup, ~210 GB суммарно):

| Модель | Папка | Содержимое |
|---|---|---|
| IQ3_XXS | `/opt/strata/models/IQ3_XXS/` | shard1 43.8 GiB + shard2 27 GiB (n-gram-таблица) |
| IQ3_S | `/opt/strata/models/IQ3_S/` | shard1 51.1 GiB + shard2 (hard-link, общий) |
| IQ2_XS | `/opt/strata/models/IQ2_XS/` | shard1 34.5 GiB + shard2 (hard-link, общий) |

Shard2 — **общий hard-link** для трёх размеров (link count 3), поэтому `du -sh` показывает
меньше суммы; подтверждены `.done`-маркеры у всех шард, `.part`-файлов не осталось.

**Конфиги** (все три, после ручного патча):
- `strata-iq3_xxs.json`, `strata-iq3_s.json`, `strata-iq2_xs.json`:
  `port: 8081`, `gpu: [0,1]`, **`gpu_order: "as_given"`** добавлен (страховка #1760),
  модельные `args` содержат базовый контекст `--max-context 32768`,
  `--vram-reserve-mib 300` + добавленный **`--vram-reserve-later-mib 2048`**
  (reserve дисплейной GPU1 — механика красной линии ≥512 MiB, факты в тикете 01);
- `run-<slug>.sh` — стартовые скрипты; модель в `/opt/strata/models/<MODEL>/`;
  vision — off (`--vision no`), parallel — дефолт (1).

**Хроника и наблюдения**:
- Установщик стартовал с **сборки из исходников** (not ready-made) — фон-процесс шёл nvcc
  по ядрам CUDA; сборка заняла ~40 мин, прошла без ошибок warnings.
- Скачивание шло по схеме «шард → шард2 shared → MTP»; HTTP-потоки к HuggingFace через
  прокси hiddify **регулярно застойли** (нет TCP-активности десятки минут) без зашитого
  самовосстановления — установщик умерал и перезапускался, черев-shard 1 IQ3_XXS (47 GB)
  докачался за 4 визита супервайзера (/opt/strata/install-logs/watchdog.log), then
  пользователь докачал IQ3_S/IQ2_XS вручную одной командой с резюмом.
- Прове́рка итога: `find models -name "*.part"` пусто, `strata --help` работает,
  `server.py --help` работает, `stack` llama-swap не тронут (движок не запускался).

**Что не сделано/не проверено** (к следующим тикетам):
- Реальный запуск движка не выполнялся (GPU/RAM не трогались) — первый
  smoke-старт в рамках тикета **Финальный протокол замеров**/**Прогон матрицы**;
- финальные контексты (базово 32768, потолок и per-model поднимут протокол);
- `--calibrate` (NVIDIA-only, до матрицы — факт/решение в тикете протокола).
