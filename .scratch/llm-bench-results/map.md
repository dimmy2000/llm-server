# llm-bench: бенчмарк трёх моделей через :8080

Status: open
Labels: wayfinder:map

## Destination

Прогнать бенчмарки репозитория https://github.com/Grigory-Rylov/llm-bench
(`bench-real-prefill.sh` + `bench-parallel-decode.py`) последовательно для трёх
публичных моделей роутера — `qwen3.8-27b` (NInfer), `strata-iq3`, `strata-iq2` —
через единую точку входа `http://localhost:8080`, и собрать результаты в таблицу
в `docs/benchmarks.md` со ссылкой на этот файл из `README.md`. Дестинация —
документ «бенчмарк прогнан, таблица в репозитории», а не спецификация.

## Notes

- **Исполняющее усилие:** дестинация — изменение на месте; task-тикиеты прогоняют
  бенчмарки прямо на карте (по одной модели на тикет/сессию), последний тикет
  собирает таблицу.
- **Протокол (решения пользователя, 2026-11-17):**
  - оба скрипта: prefill (TTFT + tok/s по глубинам, decode-пробник) и
    parallel-decode (solo-база + `--concurrency 2` для всех трёх моделей —
    потолок NInfer 2, сопоставимо);
  - глубины: `qwen3.8-27b` и `strata-iq2` — 40k/150k/200k; `strata-iq3` —
    40k + 120k (контекст 131072, дальше не влезает);
  - thinking выключен самими скриптами (`enable_thinking: false`) — меряется
    «сырая» скорость, не меняем;
  - `RUNS` — дефолты скриптов (prefill: 3 прогона/глубина + decode-пробник).
- Прогоны строго последовательны (exclusive-группа: ровно один резидентный
  движок); warmup скриптов впитывает холодный старт после свапа (NInfer ~6–9 c,
  Strata 13–21 c).
- Сырые stdout прогонов → `.scratch/llm-bench-results/assets/run-<model>/`;
  клон llm-bench и его `realdata/` (чанки) — в `/home/dimmy/projects/00 infra/llm-bench`
  (сосед репозитория; в git этого репозитория не попадает).
- Метрики движка (блок `timings`) — фича Strata; для NInfer скрипт фоллбечит на
  client-side tok/s — в таблице пометить, где какая.
- Красные линии во время прогонов: ≥ 512 MiB свободной VRAM на дисплейной GPU1,
  без постоянного свопа.
- Документация на русском, сообщения коммитов — английский Conventional Commit
  (ASCII, ≤ 72 символа).
- Скиллы: /research (тикет 01), /grilling (02, 08), /prototype (03).

## Decisions so far

- [Совместимость llm-bench с роутером :8080](issues/01-router-compat.md) — стриминг (prefill/parallel) работает как есть: у NInfer в стриме есть и `usage`, и `timings`; обходы: в prepare/make-chunks патчем заменить хардкод `model: "bench-prepare"` на реальный ID (через роутер 404) и снизить warmup-коэффициент prefill `depth//12`→`depth//15` (iq3@120k иначе не влезает в ctx); parallel требует make-chunks.py (числовые слоты); MODEL/--model задавать явно (порядок /v1/models — алфавитный)
- [Протокол: подтверждение замеров по итогам тикета 01](issues/02-protocol-confirm.md) — протокол зафиксирован: два sed-патча рабочей копии клона (модель-счётчик qwen3.8-27b, warmup `depth//15`) + FLUSH=0; MODEL всегда явно; порядок — «с текущего резидента» (iq3→iq2→qwen); parallel — канон (solo 2 прогона offset 0 + c2 3 прогона offset 100, чанки 40k)
- [Клонируем llm-bench и готовим чанки](issues/04-clone-prepare.md) — клон в `00 infra/llm-bench` на пин-коммите `bde1a22` (2026-11-11) с патчами (diff в `assets/04-clone-patch.diff`); 36 чанков собраны (40k×18, 120k/150k/200k×6, все в допуске ±0.5%); нюанс: manifest.json содержит 18 записей (FORCE=1 pass B перезаписал pass A) — скрипты его не используют, файлы на диске полные
- [Скелет docs/benchmarks.md и формат таблицы](issues/03-table-skeleton.md) — скелет одобрен: строки = модель×глубина, три таблицы (prefill/decode/parallel), секции Среда/Протокол/таблицы/Условия/Сырые данные; ссылка в README — отдельная секция «Бенчмарки» (черновик в `assets/prototype-03-benchmarks-skeleton.md`)
- [Прогон: qwen3.8-27b (NInfer)](issues/05-run-qwen38-27b.md) — полный прогон чистый (кэш-контаминации 0, без свопа, без FAIL): prefill 40k/150k/200k = 5 185/3 049/2 541 tok/s (engine) при TTFT 7.7/49.6/79.0 s; decode-пробник 131/73/70 tok/s (MTP 26/21/19%); parallel 40k: solo 108.6 tok/s на поток, c2 сумма потоков 127.9 (+18%), aggregate 15.1 vs 14.8; аномалия: мин. свободная VRAM GPU1 = 320 MiB (ниже красной линии 512) в фазе 200k — без последствий; prompt_tokens снять пост-пробами (QUIET=1 их не печатает) — сделать то же в 06/07
- [Прогон: strata-iq3](issues/06-run-strata-iq3.md) — чистый прогон (кэш-контаминации 0, свапов нет, без FAIL): prefill 40k/120k = 4 517/4 658 tok/s (engine) при TTFT 8.9/25.9 s; decode-пробник 109.6/109.2 tok/s (MTP 60/53%); parallel 40k: solo 119.5 tok/s на поток, c2 сумма потоков 243.9 (+104% к solo) при aggregate 12.9 vs 12.8 (×1.00 — второй поток платит +9.9 s за очередь префила); VRAM GPU1 min 1 516 MiB (красная линия не затронута; 710 MiB — только в эпизоде чужого свапа в qwen3.8-27b), постоянного свопа нет. Чанки 40k/120k пересобраны с нового текста (ptok 40 008/120 489) — их же получит тикет 07. Первая попытка — свап-гонка (task-агент думал на qwen3.8-27b): 4 из 13 TTFT раздуты (120k mean 47.2 s вместо 25.9), engine-метрики той попытки чистые → `assets/run-strata-iq3/attempt1-swap-race/`; вывод для 07: рассуждения агентов на резидентном движке раздувают TTFT, замерный вызов делать без ассистентских шагов внутри (сервис-режим)
- [Прогон: strata-iq2](issues/07-run-strata-iq2.md) — чистый прогон (cached=0/0 во всех замерных ранах, свапов в окне нет, FAIL нет, постоянного свопа нет): prefill 40k/150k/200k = 4 591/4 734/4 704 tok/s (engine) при TTFT 8.75/31.7/42.7 s; decode-пробник 126.2/119.0/121.9 tok/s (MTP 68.6/61.6/77.1%, expert cache 88.8–97.6%); parallel 40k: solo 124.8 tok/s на поток (aggregate 13.1), c2 сумма потоков 246.4 (×1.97 к solo, ×1.01 к iq3-канону 243.9) при aggregate 13.1 (×1.00); VRAM GPU1 min 1 598 MiB в фазе c2 (красная линия 512 не затронута); RAM available 17.2 → 17.0 GiB (ниже ожидавшихся 20–23), своп 318 MB без изменений. Свап-гонка была ДО окна (три свапа 16:04–16:06Z), RAM-гейт прошёл без отказа
