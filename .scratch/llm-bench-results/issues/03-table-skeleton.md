Status: resolved
Type: prototype
Blocked by: 02

## Question

Сделать скелет `docs/benchmarks.md` и показать пользователю для реакции
(прототип — черновик файла, к которому пользователь реагирует):

- структура файла: заголовок (что это, источник — репозиторий llm-bench +
  пин коммита, дата прогонов, версии стека: llama-swap v265 / NInfer v0.4.6 /
  Strata 0.1.45, железо 2× RTX 5070 Ti + 59 GiB RAM), протокол (глубины, runs,
  thinking off, ровно один резидентный движок), затем секции по группам метрик:
  prefill по глубинам (TTFT, tok/s engine/client, флаги кэш-контаминации),
  decode-пробник (tok/s, MTP accept), parallel decode (solo vs c2: per-stream
  и aggregate tok/s), ссылки на сырые прогоны (assets), примечания (красные
  линии VRAM, аномалии);
- схема колонок каждой таблицы (модели строками или колонками — решить и
  показать);
- куда в `README.md` вешать ссылку (кандидат: новая строка «Бенчмарки» в
  секции «Схемы работы» либо отдельная секция).

Результат: одобренный скелет (черновик файла — в ответе тикета или закоммиченный
`docs/benchmarks.md`-скелет — решить с пользователем); заполнение данных —
тикет «Таблица в docs/benchmarks.md + ссылка из README».

## Answer

Скелет одобрен пользователем 2026-11-17 (черновик —
`assets/prototype-03-benchmarks-skeleton.md`):

1. **Схема таблиц — (a)**: строки = модель×глубина, три таблицы
   (prefill / decode-пробник / parallel decode) — как в черновике.
2. **Набор секций** — как в черновике: Среда / Протокол / три таблицы /
   Условия прогонов / Сырые данные.
3. **Ссылка в README.md — отдельная секция «Бенчмарки»** (после «Схемы
   работы»), с ссылкой на `./docs/benchmarks.md` (вариант «строка в списке
   Схемы работы» отклонён).
4. Заполнение числами — тикет «Таблица в docs/benchmarks.md + ссылка из
   README»; пин коммита llm-bench — из ответа тикета «Клонируем llm-bench и
   готовим чанки».
