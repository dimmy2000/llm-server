# Strata: интеграция strata-iq3 / strata-iq2 в llama-swap

Status: open
Labels: wayfinder:map

## Destination

Strata (Qwen3.8-Flash-Next) доступна повседневно: llama-swap на `:8080` публикует публичные ID
**`strata-iq3`** (IQ3_XXS @131072) и **`strata-iq2`** (IQ2_XS @262144) рядом с родительским
`qwen3.8-27b`; нативная Strata на хосте сопровождается systemd-юнитом и включается/выбирается
оркестрирующим скриптом (последовательный доступ — ровно один бэкенд резидентен); opencode
и потребители переведены; ADR-0007 + AGENTS.md + runbook отражают новую топологию. Пилот на
рабочих задачах идёт на этой конфигурации по критериям отчета 0016 §10.1 (решение
карты selection (0016) не пересматривается).

## Notes

- Решения стартовой фазы (гриллинг перед созданием карты, подтверждены пользователем):
  - Вариант A — полноценная эксплуатация через llama-swap; llm-monitoring не включается
    (проект требует переработки — вне карты; метрики Strata видны в собственном мониторинге
    и journald нативного юнита).
  - Последовательный доступ: физика RAM (XXS 43 GB + XS 35.5 GB экспертов > 59 GiB) не
    допускает резидентности двух размеров (или Strata рядом с llama.cpp `--cache-ram`);
    поэтому выбор ролей пользователя — последовательный.
  - Публичные ID: `strata-iq3` и `strata-iq2` — осознанный пересмотр ADR-0006
    («ровно один ID»); родительский `qwen3.8-27b` сохраняется как есть.
  - Lifecycle: systemd-юнит + оркестрирующий скрипт — единственная точка правды
    переключения (стоп/старт юнита, health `:8081`, `PUT /api/profiles/active` / `/unload`,
    порядок RAM/VRAM).
- **Исполняющее усилие:** task-тикиеты меняют конфиги и код прямо на карте — пункт назначения
  это артефакт «инфраструктура обновлена и работает», не отдельная спецификация.
- Железо/стек: 2× RTX 5070 Ti (16 GB, GPU1 дисплейная, красная линия ≥ 512 MiB), 59 GiB RAM,
  драйвер 615.71.09-p2p. Родительский стек: llama-swap v265 на `:8080` (`AGENTS.md` в корне).
  Strata нативно на хосте `/opt/strata`, движок CUDA 13.3, эндпоинт `:8081`, конфиги трёх
  размеров готовы (IQ3_S тоже — как runner-up).
- Feasibility и механизмы llama-swap v265 разрешены закрытой картой
  `.scratch/strata-model-selection/` (тикет 02): shim-модель (`cmd: sleep infinity`,
  `proxy: http://<host>:8081`, `checkEndpoint: /health`), hooks не умеют команд, unix-socket
  мёртв, health-check внешнего URL работает; честность «ID ↔ реально загруженный размер» обеспечивается оркестратором.
- Замеры и решение о размерах — `docs/research/0016-strata-flash-next-selection.md`;
  критерии годности и потолки — из матрицы; в этой карте метрику не перепроверяем
  (санити-проверка decode после интеграции — да, полный матричный re-run нет).
- Env-nuances opencode для Strata: запуск с `env -u http_proxy -u https_proxy` (прокси ломает
  bun-fetch), имя провайдера не `llama-swap` (конфликт с глобальным — использовать уникальное,
  в прошлой карте было `strata-s`), всегда `--standalone` для headless.
- Язык сессий и отчета — русский. Навыки: `/grilling` для развилок, `/research` для
  research-тикетов; внешние репо `../llama-swap` (v265 код) и его docs — по мере надобности.
- Артефакты (raw-логи верификации) класть в `.scratch/strata-integration/assets/` и в git
  коммиты конфигов (ADR/runbook — в документацию репозитория).

## Decisions so far

- [Конфигурация llama-swap: strata-iq3 / strata-iq2](issues/01-llamaswap-config.md) —
  шимы прямо под публичными ID без useModelName; два страта-профиля пинят
  родителя и соседний размер, в родительских профилях страта-ID закрыты;
  порт 8081, привязка docker0 172.17.0.1 — сервер не виден с LAN
  (8081 освободила остановка llm-monitoring 2026-10-19 — её контейнеры
  стоят, `unless-stopped` переживает reboot; см. тикет 01 / Comments);
  fast-fail через watchdog-shim (пер-модельный healthCheckTimeout в v265
  не работает, load.go:136); тикет 02 получает порядок «unload → юнит →
  /health → profile» и ExecStop-добивание дерева.

## Not yet specified

- **Пилот на рабочих задачах**: чеклист наблюдаемых сигналов (деградации #1944-типа на
  длинных сессиях, CJK-коллапс, thinking-обрывы без закрытия блока, RAM-пресура/своп при
  ежедневной нагрузке) — точное содержание станет оспецифицируемым после настройки
  интеграции; арбитраж пересмотра решения 0016 — качественные критерии уже в §10.1 отчета.
- **RAM-баланс «родительский стек idle ↔ Strata резидент»**: llama.cpp держит до ~40 GB
  cache-ram на idle — тикет 01 подтвердил, что kill/unload родительского бэкенда
  освобождает его RAM (page-locked) за секунды, вмешательства «рестарт
  контейнера» скорее всего не понадобится — окончательное решение за юнитом
  тикета 02; если простое решение не найдётся — выделится в отдельный тикет.
- **Windows port-forwarding** (`scripts/port-forwarding-rules.ps1` хоста): нужен ли
  `:8081`/новые роуты для потребителей вне WSL — уточнить при готовом стеке
  (тикет 01 предварительно: снаружи потребителей новый маршрут не нужен, всё через `:8080`).

- **vLLM-профиль** — как и раньше: вне текущего усилия.
- **Апгрейд RAM** — инфраструктурное решение вне этой карты.
- **Формальные eval'ы качества** — out of scope (утверждено картой selection 0016; решение
  о качестве принял пользователь).
- **Решение о «какой размер держать постоянно»** — принято в 0016 (двухмодельная схема,
  условная до пилота). Эта карта его не пересматривает, только делает работу из него достижимой.
- **IQ3_S параллельная ветка** (runner-up, условный) — вернется отдельным тикетом при
  починке апстрим-блокера `--resident-experts`, не в этой карте.
