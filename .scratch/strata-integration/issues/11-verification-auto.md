## Question

(Исполнение; сырьё — `.scratch/strata-integration/assets/11-*.md`) Проверить
автомат на живом железе по критериям первой итерации (адаптированным под
отсутствие ручных шагов):

- **Цикл свопов по HTTP-запросам** (без единой команды переключения): qwen →
  iq3 → iq2 → qwen (ninfer-роль, если решением 09 предусмотрена) — минимум ×2,
  все шаги 200, тайминги воспроизводимы; холодные загрузки против известных норм
  (llama.cpp 40–60 c, Strata ~15–25 c — в контейнере перепроверить, NInfer ~6 c).
- **Честность листинга:** `/v1/models` всегда показывает три ID; ответы не ломаются
  на смене бэкенда; `model` в ответе strata-шим — канон native-ID (не сверять с
  запрошенным — контракт первой итерации).
- **Красные линии:** GPU1 ≥ 512 MiB в пиках переходов; RAM available — без ухода
  в своп (транзиентные всплески старта iq3 — норма); OOM-сценарий по политике 08
  воспроизводится предсказуемо.
- **Ребут-тест:** после перезагрузки хоста автомат приходит в рабочее состояние
  без ручных шагов (сравнить со старой проверкой «юнит linked, НЕ enabled»).
- **Конкурентность:** запрос к другому ID во время идущего свопа — поведение по
  семантике llama-swap (очередь/отказ), зафиксировать факт.
- **Санити-decode** Strata обоих размеров в допуске 0016 (iq3 ~130, iq2 ~145 ±20 %).
