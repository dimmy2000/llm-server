# Санити-decode обоих strata-размеров через :8080 (тикет 04, 2026-10-19)

Методика: один chat-запрос на размер (в его окно цикла), reasoning off
(`chat_template_kwargs: {"enable_thinking": false}` — механика подтверждена
тикетом 03), max_tokens 300, генеративный промпт («рассказ про маяк», 41
prompt-токен), temp — серверный дефолт. tok/s: (a) из журнала движка —
`300 generated in X ms (Y tok/s)` (первичный, ровно completion/время генерации),
(b) контрольный расчёт usage.completion_tokens / wall curl (включает префилл и
HTTP-оверхед — систематически занижает). Admission — `drafts accepted A of B`
из того же журнала (`/opt/strata/strata-*.log`). Норма ~130 (iq3) / ~145 (iq2)
tok/s ±20 %; admission 46–93 %.
